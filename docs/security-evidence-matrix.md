# Security evidence matrix

Each claim below is mapped to the code that implements it, the exact automated test, the exact command, the expected behaviour, the outcome of running that command on 2026-10-11, and the limits. Commands run from the repository root with the project venv:

    PYTHONPATH=. .venv/Scripts/python -m pytest -q <test id>

Full suite on 2026-10-15: `1170 passed, 2 skipped` (offline, about 2 minutes) (the 2 skips are the live FISCO and live PQ-TLS tests, which need a running chain/proxy). All tests are hermetic (offline forced, outbound sockets blocked, in-memory or tmp databases).

**Evidence types** used below: code inspection / automated test / manual test / independent verification. No independent verification exists today: there has been no independent audit, penetration test or certification of any kind. A claim without an automated test is labelled a gap.

**What this is not.** This repository has not been certified, accredited or independently audited by anyone, and the matrix does not claim otherwise. It is the authors' own evidence that specific behaviours are exercised by specific automated tests in a sandbox with simulated money. A passing test shows the tested behaviour for the tested inputs, not the absence of other flaws. The same team wrote the attacks and the defences. See [security-self-assessment.md](security-self-assessment.md) for the threat model and the Known limitations list.

## Gaps (no automated test, or only indirect)

- No dedicated test that changes only the payee id between approval and execution (row 5 uses account and amount changes).
- PQ-TLS handshake and live FISCO anchoring have no test that runs by default; they are manual, recorded runs (row 14).
- No automated test that Secure-cookie, HSTS or TLS are applied by the app itself: it serves plain HTTP (Known limitation 4).
- No automated test for key-file permissions on Windows (they are not restrictive; see row 8).
- Chat understands only the phrasings its keyword router knows (`tests/test_chat_nlu.py`); an unrecognised sentence gets a help message, never a guess. The optional model label for chat has two small live runs (`eval/reports/chat_llm.md`: 0 of 4 traps became a payment label in both) and is otherwise tested with a fake model.
- No fuzzing, load, side-channel or third-party penetration test. Claims of "certified", "audited" or "secure" are not made anywhere in this repository (checked by searching README, docs and PROGRESS on 2026-10-11).
